## 路由设计

| 路径 | 页面/用途 | 新增/修改 | 传参方式 |
|------|---------|---------|---------|
| `/login` | 登录 + 首登改密 | 修改 | 无 |
| `/` | `AdminLayout`，重定向 `/dashboard` | 新增 | 无 |
| `/dashboard` | 仪表盘 | 新增 | 无 |
| `/library` | 动作库 | 新增 | 无（可后续扩展 query `category`） |
| `/console` | 桌宠控制台 | 新增 | 无 |
| `/trash` | 回收站 | 新增 | 无 |
| `/audit` | 审计日志 | 新增 | 无 |
| `/health` | 健康检查 | 新增 | 无 |
| `/settings` | 设置（改密） | 新增 | 无 |
| `/:pathMatch(.*)*` | 兜底重定向 `/dashboard` | 新增 | 无 |

**跳转关系**：
- 侧栏菜单项 → 对应子路由（`/dashboard` … `/settings`）。
- 登录成功 → `router.replace('/dashboard')`；登出/401 → `router.replace('/login')`。
- 编辑动作弹窗不占路由（组件内 `el-dialog`）；首登改密不占路由（Login 内子流程）。

**路由守卫**（`router.beforeEach`）：
- 鉴权态由 `src/stores/auth.js` 单例持有：`state = { checked, user }`，提供 `checkAuth()`（首次 `api.me()` 并置 `checked=true`）、`setAuthed(user)`、`clearAuth()`。
- 首次导航异步 `checkAuth()` 判定登录态并缓存，避免重复请求。
- 目标为 `/login`：已登录 → `replace('/dashboard')`；未登录 → 放行。
- 目标为受保护路由：未登录 → `replace('/login')`；已登录 → 放行。
- **缓存失效机制**：登录成功（Login 调 `api.login` 成功后）→ `setAuthed(user)` 后 `router.replace('/dashboard')`；登出或任意非 `/api/auth/*` 接口返回 401（经 api.js 钩子）→ `clearAuth()` 后 `router.replace('/login')`。保证登录态变化后守卫判定即时更新，避免「登录成功却被守卫弹回」。
- 守卫执行前渲染全局加载态（`App.vue` 内 `authReady` 门控），避免闪登录页。

## 数据流 / 状态管理

- **全局 store**：新增 `src/stores/assets.js`，模块级 `reactive/ref` 单例（composable `useAssetsStore()`），不引入 Pinia（应用规模小，单例足够）。持有：`items`、`stats`、`health`、`trashItems`、`auditLogs`、`commands`，及 `loadResources()/refreshHealth()/loadTrash()/loadAudit()/loadCommands()/pendingCount()`；并新增 computed `catCounts`（由 `items` 按 `category` 聚合，供仪表盘分类条与动作库分类 chips 共用）。
- **401 统一处理**：`src/api.js` 的 `request()` 增 `setUnauthorizedHandler(fn)` 钩子；对**非 `/api/auth/*`** 路径返回 401 时触发 `fn`（登录/改密的 401 属业务失败，走各自错误提示，不触发登出）。`main.js` 初始化时注册 `fn = () => { clearAuth(); router.replace('/login') }`，实现任意读/写接口会话失效后的自动登出。
- **组件 state**：各视图内部过滤/表单状态（如 `search/catFilter/sortBy/uploadCat/editVisible/…`）留在视图组件内，不进全局 store。
- **URL 参数**：路由路径即视图标识；`/library` 预留 query `category`（本次不强制）。
- **本地缓存**：无新增（现状 localStorage 仅任务看板等外部插件使用，本前端不引入）。
- **现有状态是否需要改造**：是。原 `Admin.vue` 内的 `items/stats/health/trashItems/auditLogs/commands` 上收至 `useAssetsStore()`；`activeMenu/collapsed` 状态改为由 `route.path` 派生 + 布局局部 `collapsed`。健康轮询 `setInterval(refreshHealth,10000)` 由 `AdminLayout` 负责并在 `onBeforeUnmount` 清理。
